# SiteWatch — جديد المواقع اليوميّة في بوت تيلغرام واحد

يفحص هذا البوت كلّ ساعة المواقع التي تتابعها، ويرسل ما جدّ فيها إلى بوت تيلغرام. يعمل على خوادم GitHub، فلا يحتاج إلى جهازك.

## المصادر
| المصدر | ما يُرسل | الطريقة |
|---|---|---|
| يوتيوب | كلّ فيديو جديد من القنوات التي تشترك فيها | YouTube Data API؛ والقنوات من اشتراكاتك العامّة، فتتحدّث وحدها |
| Anikoto | كلّ حلقة مترجمة جديدة | صفحة الفرز (الأحدث تحديثًا) |
| WCO | الحلقات الجديدة | خلاصة RSS |
| كراتين | الحلقات الجديدة | متصفّح خفيّ (بيانات الموقع مشفّرة) |
| توب سينما | الأفلام والحلقات الجديدة | خلاصة RSS |
| Impractical Jokers | كلّ حلقة عُرضت | واجهة TVmaze، والرابط إلى صفحة المسلسل في telepisodes |
| FileCR | ما يظهر في الصفحة الرئيسيّة: ويندوز، ألعاب، أندرويد | بيانات الصفحة |
| FitGirl Repacks | كلّ منشور جديد | خلاصة RSS |
| GitHub | الإصدارات الجديدة للمستودعات المميّزة بنجمة | واجهة GitHub |
| EgyDead | الحلقات الجديدة | روابط صفحة الحلقات (يحجبها Cloudflare عن جهازك، ولا يحجبها عن خوادم GitHub) |

- **المعطّلة:**
  - **WitAnime:** يحجبه Cloudflare عن البرامج، من جهازك ومن خوادم GitHub.
  - **telepisodes:** يُفتح من خوادم GitHub، لكنّ حلقات Impractical Jokers تؤخذ من TVmaze لأنّه أثبت.
  - كلاهما في الإعدادات بـ`"enabled": false`، ويجرّبهما فحص المصادر.
- **أوّل فحص لكلّ مصدر يسجّل ما فيه ولا يرسله**، حتّى لا يصلك سيلٌ من القديم. وكذلك القناة أو المستودع حين يُضاف.
- إن زاد جديد مصدرٍ واحد على 10 في فحصٍ واحد، جُمع في رسالةٍ واحدة.
- إن تعذّر فحص مصدرٍ 3 مرّاتٍ متتالية، يصلك تنبيه، ثمّ رسالة حين يعود.
- **يوتيوب:** خلاصات القنوات تتعطّل عند يوتيوب من حينٍ لآخر (ترجع «غير موجود» حتّى للقنوات الموجودة). فالقناة التي تتعطّل تُتخطّى في ذلك الفحص، وفيديوهاتها تصل في أوّل فحصٍ تعمل فيه، لأنّ الخلاصة تحمل آخر 15 فيديو. ولا ينبّهك البوت إلّا إن تعطّلت القنوات كلّها 24 فحصًا متتاليًا (يومًا).

## الإعدادات والأسرار
- المصادر في `config.public.json`. لإيقاف مصدرٍ اجعل له `"enabled": false`.
- الأسرار في Settings ← Secrets and variables ← Actions:
  - `TELEGRAM_TOKEN`: رمز البوت من BotFather.
  - `TELEGRAM_CHAT_ID`: رقم محادثتك مع البوت.
  - `YT_SUBSCRIBER`: رابط قناتك في يوتيوب. يقرأ البوت منه اشتراكاتك في كلّ فحص، فالقناة التي تشترك فيها تدخل وحدها (تُسجَّل فيديوهاتها الحاليّة بلا إرسال)، والتي تلغي اشتراكك فيها تخرج. ويلزم أن تبقى اشتراكاتك عامّة (يوتيوب ← الإعدادات ← الخصوصيّة).
  - `YT_CHANNELS`: احتياط: معرّفات قنوات (تبدأ بـ UC)، كلّ واحدٍ في سطر. لا تُستعمل إلّا إن تعذّرت قراءة الاشتراكات (إن صارت خاصّة مثلًا)، وهي قائمة Takeout الثابتة.
  - `YT_API_KEY` (اختياريّ): مفتاح YouTube Data API. إن وُجد قُرئت القنوات منه، وهو ثابت، وإلّا فمن خلاصاتها العامّة التي تتعطّل أحيانًا. وفحص 200 قناة كلّ ساعة نحو 5,000 وحدةٍ في اليوم (وحدةٌ لكلّ قناة، وأخرى لكلّ 50 من الاشتراكات)، والحدّ المجّانيّ 10,000.
- ما أرسله البوت محفوظ في `state.json`، يرفعه بعد كلّ فحص، فلا يتكرّر شيء.

## كيف يتكرّر الفحص
جدولة GitHub لا يُعتمد عليها وحدها، فكلّ تشغيلٍ ينتهي بمهمّة `wake`. تنتظر 60 دقيقة (مؤقّت البيئة `wake-60`)، ثمّ تطلب التشغيل التالي. وجدولة GitHub كلّ 3 ساعات احتياطٌ يعيد السلسلة إن انقطعت. وإن تعذّر طلب التشغيل التالي، يصلك تنبيه.

**تنبيه:** مؤقّت الانتظار لا يتوفّر للمستودعات الخاصّة في الخطّة المجّانيّة، فيلزم أن يبقى المستودع عامًّا.

## الاستعمال
- **تشغيل فوريّ:** تبويب Actions ← sitewatch ← Run workflow.
- **رسالة اختبار:** مثله، مع علامة على «أرسل رسالة اختبار فقط».
- **ما نُشر في آخر ساعات:** Actions ← send-recent ← Run workflow، واكتب عدد الساعات. يرسل من كلّ مصدرٍ يذكر وقت النشر، ولا يغيّر الحالة. وAnikoto وكراتين وEgyDead لا تذكر وقت النشر.
- **فحص المصادر:** Actions ← probe-sources ← Run workflow. يطبع ما يجده في كلّ مصدر، دون إرسال ودون تغيير الحالة.
- **الإيقاف:** Actions ← sitewatch ← ⋯ ← Disable workflow. **وللإعادة:** Enable workflow، ثمّ Run workflow مرّةً واحدة.

## على الجهاز
```
pip install -r requirements.txt
python sitewatch.py --probe
```
`--probe` يجرّب المصادر، و`--dry` يطبع الجديد بلا إرسال ولا حفظ.
