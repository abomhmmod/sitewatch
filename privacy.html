Privacy Policy

Last updated: 9 November 2026

SiteWatch is a personal tool used only by its owner. This policy describes how it handles Google user data.

Data accessed

With the owner's permission (the YouTube scope), SiteWatch reads the list of the owner's YouTube playlists and adds videos to them when the owner presses a button in his own Telegram chat. It also reads public YouTube data (public subscriptions and channel uploads) with an API key.

Use

The data is used only to show new videos to the owner and to add the videos he chooses to his own playlists. It is not used for advertising, profiling, or any other purpose.

Storage and sharing

The authorization token is stored as an encrypted GitHub Actions secret. No Google user data is sold, shared with, or transferred to any third party. The only record kept is a list of item identifiers already sent, so nothing is sent twice.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

SiteWatch's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
